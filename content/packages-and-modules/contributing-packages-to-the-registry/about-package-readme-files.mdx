# 🌀 react-scrollfix

A tiny React utility that automatically scrolls the page to the top whenever the route changes — ideal for single-page apps using **React Router**.

---

## 🚀 Install

```bash
npm install react-scrollfix
```

or

```bash
yarn add react-scrollfix
```

---

## 💡 Usage

Place `<ScrollFix />` inside your main router so it runs on every route change.

```jsx
import React from "react";
import { BrowserRouter as Router, Routes, Route, Link } from "react-router-dom";
import ScrollFix from "react-scrollfix";

function Home() {
  return (
    <div style={{ height: "200vh" }}>
      <h2>Home Page</h2>
      <p>Scroll down, then navigate to test ScrollFix.</p>
    </div>
  );
}

function About() {
  return (
    <div style={{ height: "200vh" }}>
      <h2>About Page</h2>
      <p>ScrollFix resets scroll position automatically!</p>
    </div>
  );
}

export default function App() {
  return (
    <Router>
      <ScrollFix />

      <nav style={{ position: "fixed", top: 0, background: "#fff", width: "100%", padding: "10px" }}>
        <Link to="/" style={{ marginRight: "10px" }}>Home</Link>
        <Link to="/about">About</Link>
      </nav>

      <div style={{ marginTop: "60px" }}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/about" element={<About />} />
        </Routes>
      </div>
    </Router>
  );
}
```

✅ When you change routes, the page scrolls back to the top automatically.

---

## ⚙️ API

### `<ScrollFix />`

No props required.

* **Automatically** detects route changes via `useLocation`
* Triggers `window.scrollTo(0, 0)` on every navigation
